# interview-audio-review

将面试录音转写为带时间戳的文字稿，并生成结构化的面试复盘报告。报告逐题区分面试官问题、候选人回答、回答评价和推荐回答，适合复盘技术面试与沉淀学习计划。

## 功能

- 复用同项目的 `transcribe-audio` skill 完成本地转写；
- 默认以 `small` 模型处理中文面试音频，音质差或术语密集时可改为 `medium`；
- 根据时间戳区分提问与回答，并标注自动转写中无法确认的专有名词；
- 每道题输出“问题—回答概述—评价—推荐回答”；
- 输出整体评价、优势、优先改进项和可练习的知识点；
- 将文字稿与报告固定保存到项目根目录的 `interview-reviews/`。

## 依赖

本 skill 依赖相邻目录的 [`transcribe-audio`](../transcribe-audio/README.md) skill。首次使用前，先根据其说明安装 `faster-whisper` 和下载模型。

## 工作流

```text
面试音频
   ↓
transcribe-audio：生成带时间戳文字稿
   ↓
识别提问、回答与转写不确定项
   ↓
逐题分析并生成推荐回答
   ↓
interview-reviews/：保存文字稿与 Markdown 报告
```

## 报告命名

报告标题根据是否可靠识别出公司名称确定：

- 未提供或无法可靠识别公司名称：`YYYY年MM月DD日面试复盘`；
- 提供或可可靠识别公司名称：`{公司名称}面试复盘`。

文件始终保存在 `interview-reviews/`：

```text
interview-reviews/
├── YYYY-MM-DD-面试复盘.md
└── YYYY-MM-DD-{公司名称}-面试复盘.md
```

若同名文件已存在，新增报告应追加 `-2`、`-3` 等序号，不覆盖历史复盘。

## 报告结构

```md
# {报告标题}

## 整体评价

## 逐题复盘

### 1. {问题主题}

**面试官问题**

**候选人回答概述**

**评价**

**推荐回答**

## 优先补齐的知识与练习
```

## 使用边界

- 复盘基于音频中的实际表达；推荐回答必须与原回答明确区分。
- 自动转写的模型、框架和人名可能有误，无法从上下文确认时应标记为“转写待核”。
- 不修改或删除原始音频。
